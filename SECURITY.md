# Security Policy

## Educational & Research Scope
This repository contains an adversarial evaluation harness and defense benchmarking suite for autonomous AI agents. All exploit scenarios and defense primitives are intended solely for authorized security evaluation, model safety audits, and academic research.

## Reporting Vulnerabilities
If you identify security issues or unhandled evasion vectors in the mitigation filters:
- **Do not** disclose vulnerabilities via public GitHub issues.
- Contact the maintainer directly at: **btsiamouras@gmail.com** or via [LinkedIn](https://www.linkedin.com/in/vasilis-tsiamouras/).
- Coordinated disclosures will be credited and incorporated into subsequent benchmark releases.
